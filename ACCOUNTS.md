# Crypto Alpha / Early-Signal Follows (audited shortlist)

> Compiled 2026-10-02 (Australia/Perth, AWST). Companion to the education list at [crypto-quality-follows](https://biggles10-claude.github.io/crypto-quality-follows/) — **this page is for early-signal hunting, not fundamentals school.**

## Honesty first (read this)

- **True exclusive alpha is rare.** If 50 people on CT can see it, it is already competing for the same JUMP/Echo/Legion fill, the same Solana sniper slot, or the same unlock fade.
- Following this list **will not** get you exclusive allocations, guaranteed 10x launches, or a private whale club. It improves *information hygiene* and *reaction time*.
- Many "alpha" accounts are **crowded**, **affiliate-linked**, or **portfolio-biased**. Caveats are not decoration.
- **Protecting capital is alpha.** Security / scam hunters are intentionally over-weighted.
- Deduped against the 80-account quality/education list, except `@zachxbt` (kept here as a scam-filter).
- Size bias: prefer ~1k–150k when possible; some larger accounts kept only if they still post early actionable signal. Mega accounts are flagged.
- Not financial advice. On-chain labels lie. Screenshots forge. DYOR.

## How to use

1. **X Lists, not Follow-all.** Make separate Lists: `deal-flow`, `on-chain`, `security`, `research`, `trading-ms`, `apac`. Mute reply-guy keywords (`100x`, `DM me`, `VIP`, `guaranteed`).
2. **Never ape Telegram/Discord VIP invites** from people you discovered via a viral thread. Public receipts or it doesn't exist.
3. **Process > tickers.** Prefer accounts that show wallets, Dune links, unlock schedules, or audit diffs over those who only post rockets.
4. **Asia session matters in Perth.** Pin `EmberCN`, `ai_9684xtpa`, `WuBlockchain`, `mrjasonchoi`, `StalkHQ` for morning tape.
5. **Cross-check unlocks and flows** on primary tools (Tokenomist, Dune, explorers) before sizing.
6. Start with the **Starter Pack 10** below; add categories only when you can process the noise.
